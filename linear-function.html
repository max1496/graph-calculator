Linear Function: y = ax + b

Find the line through two points

What is a linear function?

A linear function is a function whose graph is a straight line. It is written y = ax + b, where a and b are fixed numbers. Every time x goes up by 1, y changes by the same amount, and that amount is a.

What a and b mean

  • Slope (a) tells you how steep the line is. A positive slope rises from left to right, a negative slope falls, and a slope of 0 gives a flat horizontal line.
  • y-intercept (b) is where the line crosses the y-axis, the point (0, b).
  • x-intercept is where the line crosses the x-axis. Set y = 0 and solve: x = −b / a. A flat line has none unless it lies on the axis itself.

How to graph a linear function

  1. Plot the y-intercept (0, b).
  2. From that point, move 1 unit right and a units up (down if a is negative).
  3. Draw a straight line through the two points and extend it in both directions.

Find the equation from two points

Given two points (x1, y1) and (x2, y2), the slope is a = (y2 − y1) / (x2 − x1), and then b = y1 − ax1.

Example: for (1, 3) and (3, 7), a = (7 − 3) / (3 − 1) = 2 and b = 3 − 2 × 1 = 1, so the line is y = 2x + 1. Try these numbers in the tool above.

Common questions

  • Parallel lines have the same slope. Perpendicular lines have slopes whose product is −1.
  • A vertical line such as x = 3 is not a function, because one x value gives many y values. It cannot be written as y = ax + b.
