What Is a Function?

In short: A function gives exactly one output for each input. Solving an equation means asking a question about a graph.

What is a function?

  • A function is a rule that takes an input and gives back exactly one output.
  • Think of a machine: put in x, get out f(x).
  • f(x) = 2x + 1 means “double the input, then add 1”. So f(3) = 7.
  • The set of allowed inputs is the domain. The set of outputs you actually get is the range.

Is it a function?

  • Table or pairs: if the same input appears with two different outputs, it is not a function.
    (1, 2) and (1, 5) together: not a function.
    (1, 2) and (3, 2) together: fine. Two inputs may share an output.
  • Graph: the vertical line test. A vertical line must cross the graph at most once.

More on this, including one-to-one, onto and inverses, on Functions and inverse functions.

Domain and range, with a picture

Domain = every x you are allowed to put in. Look at the blue shadow on the x-axis.
Range = every y you can get out. Look at the red shadow on the y-axis.
Trick: imagine a light shining from the side (for domain) or from above (for range) onto the axis.
  • Domain problems: you cannot divide by 0 and you cannot take the square root of a negative number (in real numbers).
  • Square bracket [ ] means the end is included. Round bracket ( ) means it is not included. ∞ always gets a round bracket.
  • (0, ∞) means every number bigger than 0. [0, ∞) means 0 and everything bigger.

Equations and functions: how are they related?

  • An equation is a statement with an equals sign, like 2x + 1 = 7. It is true for some values and false for others. Solving it means finding the values that make it true.
  • A function is a rule, like f(x) = 2x + 1. It does not “solve” anything. It just turns inputs into outputs.
  • Writing y = f(x) turns the function into an equation in two variables. Its solutions are exactly the points on the graph.
The link: solving an equation = asking a question about a function’s graph.
EquationQuestion about the graph
f(x) = 0Where does the graph cross the x-axis? (zeros, roots, x-intercepts)
f(x) = 5Where does the graph meet the horizontal line y = 5?
f(x) = g(x)Where do the two graphs intersect? The x-values are the solutions.
f(x) > g(x)Where is the graph of f above the graph of g?

Example

  • Solve x² = x + 2.
  • Graph y = x² and y = x + 2 together.
  • They meet at (−1, 1) and (2, 4).
  • So the solutions are x = −1 and x = 2.
  • Check algebraically: x² − x − 2 = (x − 2)(x + 1) = 0.

Not every equation is a function. x² + y² = 9 is an equation, but it fails the vertical line test, so y is not a function of x.

The floor function (Gauss bracket)

  • ⌊x⌋ = the greatest integer that is less than or equal to x. In other words: round down.
  • This is the Gauss bracket (가우스 기호), sometimes written [x]. In the calculator type floor(x).
  • ⌊3.7⌋ = 3  ·  ⌊5⌋ = 5  ·  ⌊0.2⌋ = 0
  • Careful with negatives: ⌊−2.3⌋ = −3, not −2. Round down means toward the left on the number line.
  • The ceiling ⌈x⌉ rounds up: ⌈3.2⌉ = 4. In the calculator: ceil(x).

Why the graph is a staircase

  • Between two integers the output does not change, so you get a flat step.
  • At each integer the output jumps up by 1.
  • The filled dot on the left end of each step means the value is included (⌊2⌋ = 2).
  • The open dot on the right end means that value is not reached there.
  • This is a jump discontinuity, not an asymptote. A dashed asymptote line is for graphs that shoot off to infinity, like 1/x. The floor graph never does, so there is no dashed line.
  • Domain: all real numbers. Range: the integers only.

Where you see it

  • Parking or taxi fees charged per started hour use the ceiling.
  • The fractional part of a number is x − ⌊x⌋. Its graph is a sawtooth: try x-floor(x).
  • In programming, integer division works like a floor.

Practice

  1. Is {(1, 4), (2, 4), (3, 5)} a function?
    Show answer

    Yes. Each input appears once. Two inputs sharing the output 4 is allowed.

  2. f(x) = x² − 3. Find f(−2).
    Show answer

    (−2)² − 3 = 4 − 3 = 1.

  3. Use graphs to solve 2x + 1 = x + 4.
    Show answer

    The lines y = 2x + 1 and y = x + 4 meet at (3, 7), so x = 3.

  4. Find ⌊−1.5⌋, ⌊4⌋ and ⌈−1.5⌉.
    Show answer

    ⌊−1.5⌋ = −2, ⌊4⌋ = 4, ⌈−1.5⌉ = −1.
