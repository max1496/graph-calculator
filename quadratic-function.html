Quadratic Function: y = ax2 + bx + c

a b c

What is a quadratic function?

A quadratic function has the form y = ax2 + bx + c, where a is not 0. Its graph is a U-shaped curve called a parabola.

What a, b and c do

  • a sets the direction and width. A positive a opens upward, a negative a opens downward, and a larger |a| makes the parabola narrower.
  • c is the y-intercept. The parabola crosses the y-axis at (0, c).
  • b works together with a to move the vertex sideways, because the vertex sits at x = −b / (2a).

How to find the vertex

The x-coordinate of the vertex is

h = −b / (2a)

Put that value back into the function to get the y-coordinate k = ah2 + bh + c. The vertex is (h, k), and the vertical line x = h is the axis of symmetry.

Example: for y = x2 − 4x + 3, h = −(−4) / (2 × 1) = 2 and k = 4 − 8 + 3 = −1, so the vertex is (2, −1). The sliders above start with these values.

The vertex is the lowest point when a > 0 (a minimum) and the highest point when a < 0 (a maximum).

Vertex form

Completing the square rewrites the function as

y = a(x − h)2 + k

In this form the vertex (h, k) can be read directly. The page above shows both forms for any a, b and c you choose.

Discriminant and roots

The roots are the x-values where the parabola crosses the x-axis, that is, where y = 0. The quadratic formula gives them:

x = (−b ± √(b2 − 4ac)) / (2a)

The part under the square root is the discriminant, D = b2 − 4ac. It tells you how many real roots there are before you solve anything.

  • D > 0: two different real roots, so the parabola crosses the x-axis twice.
  • D = 0: one repeated real root, so the vertex sits exactly on the x-axis.
  • D < 0: no real roots, so the parabola never reaches the x-axis. The two roots are complex numbers.

Example: for y = x2 − 4x + 3, D = 16 − 12 = 4, so the roots are (4 ± 2) / 2, which gives x = 1 and x = 3.

Common questions

  • What if a = 0? The x2 term disappears and the function becomes a line. See the linear function page.
  • How do I tell if there is a maximum or a minimum? Look at the sign of a. Positive means a minimum, negative means a maximum.
