Algebra 1

Algebra 1 is where numbers turn into relationships. You learn to describe how one quantity changes with another using equations, graphs and tables. This page collects the interactive tools on this site that go with Algebra 1, in a sensible order to study them.

Coming next

Systems of equations, linear inequalities, exponents and exponential functions, polynomials and factoring.

How to study this unit

  • Start with linear functions. Slope and intercept are the idea that everything else in Algebra 1 builds on.
  • Move to quadratic functions once you can read a graph quickly. The sign of a and the discriminant tell you most of what the graph will look like before you draw it.
  • Use the graphing calculator to check your own answers. Solve a problem by hand first, then graph it to see whether it makes sense.

Key formulas

Slope
m = (y2 − y1) / (x2 − x1)
Slope-intercept form
y = mx + b
Point-slope form
y − y1 = m(x − x1)
Standard form of a line
Ax + By = C
Quadratic function
y = ax2 + bx + c
Vertex x-coordinate
x = −b / (2a)
Discriminant
D = b2 − 4ac
Quadratic formula
x = (−b ± √(b2 − 4ac)) / (2a)

Many textbooks write the slope of a line as m. The linear function page on this site uses a for the same thing, matching the form y = ax + b.
