Intermediate Value Theorem Calculator

Enter a function f(x), an interval [a, b] and a target value k. The tool checks whether the Intermediate Value Theorem guarantees a number c in [a, b] with f(c) = k. Use k = 0 to show that an equation has a root.

What is the Intermediate Value Theorem?

If f is continuous on the closed interval [a, b] and k is any number between f(a) and f(b), then there is at least one number c in [a, b] such that f(c) = k. In words: a continuous function cannot skip a value. To go from f(a) to f(b) its graph has to pass through every height in between.

How to use it

  1. Check that f is continuous on [a, b]. Polynomials, sin, cos and exp are continuous everywhere, but 1/x and tan(x) are not continuous at points where they are undefined.
  2. Compute f(a) and f(b).
  3. Check that k lies between them.
  4. Conclude that some c in [a, b] has f(c) = k.

Worked example: showing a root exists

Show that x³ − x − 1 = 0 has a solution between 1 and 2. Let f(x) = x³ − x − 1. It is a polynomial, so it is continuous. f(1) = −1 and f(2) = 5, and 0 lies between −1 and 5. By the Intermediate Value Theorem there is a c in [1, 2] with f(c) = 0. The calculator above finds c ≈ 1.3247.

Common mistakes

  • Forgetting continuity. For f(x) = 1/x on [−1, 1], f(−1) = −1 and f(1) = 1, but f(x) is never 0. The function is not continuous at 0, so the theorem does not apply.
  • Reading it backwards. If k is not between f(a) and f(b), the theorem says nothing. A solution may still exist, because the graph can go beyond the endpoints and come back.
  • Expecting exactly one c. The theorem only promises at least one. The tool lists every solution it finds on the interval.
  • Related result. The special case k = 0, where f(a) and f(b) have opposite signs, is sometimes called Bolzano's theorem. It is the idea behind the bisection method for finding roots.

The continuity check here is numerical, so treat it as a helpful warning rather than a proof. To explore a function on its own, use the graphing calculator, or see the polynomial from roots page.
