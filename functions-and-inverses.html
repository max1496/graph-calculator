Functions and Inverse Functions

In short: Check if a graph is a function, one-to-one or onto, then swap x and y to find the inverse.

Is it a function?

New to functions? Start with What is a function?

  • A function gives exactly one output for each input.
  • Vertical line test: if any vertical line crosses the graph twice or more, it is not a function.
  • y = x² passes the test. The circle x² + y² = 9 fails it (at x = 0 there are two points, (0, 3) and (0, −3)).

Try it: type x^2+y^2=9 in the calculator. The label under the equation tells you it fails the vertical line test.

Domain and range

  • Domain = all allowed inputs (x).
  • Range = all outputs (y) the function actually produces.
  • √x: domain x ≥ 0, range y ≥ 0.
  • 1/x: domain x ≠ 0, range y ≠ 0.

One-to-one and onto

  • One-to-one: different inputs always give different outputs.
    Horizontal line test: every horizontal line crosses the graph at most once.
  • Onto (the real numbers): every real number is an output, so the range is all of ℝ.
  • y = x³ is both (one-to-one and onto ℝ).
  • y = x² is neither: 2 and −2 both give 4, and negative numbers are never outputs.
  • y = 2x is one-to-one but not onto (outputs are only positive).
Only a one-to-one function has an inverse function.

In the calculator, open Details of graph under any equation. The Function properties section lists the domain, range, one-to-one, onto, symmetry, increasing and decreasing intervals, and concavity.

How to find an inverse

  1. Write y = f(x).
  2. Swap x and y.
  3. Solve for y.
  4. Call the result f⁻¹(x).

Example: f(x) = 2x + 3.

  • y = 2x + 3
  • Swap: x = 2y + 3
  • Solve: y = (x − 3)/2
  • So f⁻¹(x) = (x − 3)/2.

What the graph looks like

  • The graph of f⁻¹ is the graph of f reflected over the line y = x.
  • Every point (a, b) becomes (b, a).
  • Domain and range trade places.
  • f(f⁻¹(x)) = x and f⁻¹(f(x)) = x.
Not one-to-one? Restrict the domain. y = x² is not one-to-one, but on x ≥ 0 it is, and its inverse there is y = √x.

In the calculator: type an equation, open Move and reshape the selected graph and press Add inverse. A new row x = … is added. If the original is not one-to-one, you get a message and the inverse shown is not a function.

Symmetry

  • Even: f(−x) = f(x). Mirror image over the y-axis. Example: x², cos x, |x|.
  • Odd: f(−x) = −f(x). Unchanged by a 180° turn about the origin. Example: x³, sin x, 1/x.
  • Some graphs are symmetric about another line or point, for example (x − 2)² is symmetric about x = 2.

Practice

Tap “Show answer” to check.

  1. Find the inverse of f(x) = 3x − 6.
    Show answer

    x = 3y − 6, so y = (x + 6)/3. f⁻¹(x) = (x + 6)/3.

  2. Is y = |x| one-to-one? How can you restrict it so it is?
    Show answer

    No: |2| = |−2|. On x ≥ 0 it is one-to-one (and equals y = x).

  3. Find the inverse of f(x) = x³ + 1.
    Show answer

    x = y³ + 1, so y = ∛(x − 1). Try cbrt(x-1) in the calculator.

  4. Is x = y² a function of x?
    Show answer

    No. For x = 4, y = 2 or −2, so it fails the vertical line test. It is the inverse of y = x², which is not one-to-one.

  5. Find the domain of the inverse of f(x) = √x + 2.
    Show answer

    The range of f is y ≥ 2, so the inverse has domain x ≥ 2. (f⁻¹(x) = (x − 2)².)
