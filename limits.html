What is a limit?

  • A limit asks: what value does f(x) get close to as x gets close to a?
  • It does not ask what happens at x = a. The function does not even need to be defined there.
  • Written: limx→a f(x) = L

One-sided limits

  • x → a⁺ : approach from the right (values bigger than a).
  • x → a⁻ : approach from the left (values smaller than a).
  • The two-sided limit exists only if left = right.
  • Example: limx→0⁺ 1/x = +∞ but limx→0⁻ 1/x = −∞. So limx→0 1/x does not exist.

How to find a limit by hand

  1. Plug in a. If you get a number, that is the limit (for continuous functions).
  2. If you get 0/0: factor and cancel, or multiply by the conjugate.
  3. If you get number/0: check the sign on each side. The limit is ±∞ or does not exist.
  4. For x → ∞: divide by the highest power of x.
Example: limx→1 (x² − 1)/(x − 1) = lim (x − 1)(x + 1)/(x − 1) = lim (x + 1) = 2.

Limits connect to continuity and derivatives: f is continuous at a when the limit equals f(a).
