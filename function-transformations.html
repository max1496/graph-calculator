Function Transformations

In short: Pick a function, then shift, stretch, flip or rotate it. The dashed gray graph is the original and the blue graph is the new one.

The big idea: points move one way, the equation says the other

Horizontal shift: to move the graph right by h, every point moves to x + h, but you write x − h in the equation: y = f(x − h).

Why? Suppose (p, q) is a point on the original graph y = f(x). We want the new graph to contain (p + h, q). In the new equation y = f(x − h), put x = p + h. The input to f becomes (p + h) − h = p, so the output is f(p) = q. The new graph needs a bigger x to get the same output, so it is shifted right.

Example. Take f(x) = x² and g(x) = (x − 2)². The point (−1, 1) on f becomes (1, 1) on g, because (1 − 2)² = 1. The vertex (0, 0) becomes (2, 0). Everything moved 2 to the right, even though the equation says “− 2”. A plus sign, as in (x + 3)², means x − (−3), so the graph moves 3 to the left.

The same sentence works for every change that happens inside the parentheses: the equation and the points do the opposite thing.

Inside changes and outside changes

  • Outside f (after the function is computed): a·f(x) and f(x) + k. These change the y-values and behave the way they look. “+ k” moves up, and “· a” multiplies the heights.
  • Inside f (before the function is computed): f(x − h) and f(bx). These change the x-values and work backwards. “− h” moves right, and “· b” divides the widths by b.

Vertical shift

y = f(x) + k. Add k to every output. The graph moves up k units, or down if k is negative. Horizontal asymptotes move too: if f has the asymptote y = 0, then f(x) + k has y = k. The range shifts by k but the domain does not change.

Horizontal shift

y = f(x − h). See the big idea above. The domain shifts by h, and vertical asymptotes move with the graph. For example y = 1/(x − 3) has its vertical asymptote at x = 3, not −3. The range does not change.

Vertical stretch and compression

y = a · f(x). Multiply every height by a. If |a| > 1 the graph is stretched away from the x-axis. If 0 < |a| < 1 it is compressed toward the x-axis. The x-intercepts stay where they are, because 0 times anything is still 0. A negative a also flips the graph over the x-axis.

Horizontal stretch and compression

y = f(bx). The new graph reaches a given height when bx equals the old input, so x = (old input) / b. Every x-coordinate is divided by b. If |b| > 1 the graph is compressed toward the y-axis, and if 0 < |b| < 1 it is stretched away from it. The y-intercept stays where it is. In the tool above, the slider b is this number.

Careful with the wording. f(2x) is a horizontal compression by a factor of ½ (the graph gets half as wide), and f(x/2) is a horizontal stretch by a factor of 2. If you factor the inside, f(b(x − h)) shifts by h, but f(bx − c) shifts by c/b. Always factor out b first.

Reflections

−f(x) changes the sign of every output, so each point (x, y) goes to (x, −y): the graph is flipped over the x-axis. f(−x) changes the sign of every input, so each point goes to (−x, y): the graph is flipped over the y-axis. If f is an even function, f(−x) = f(x) and the second reflection changes nothing.

Rotation

Turning the graph about the origin by θ sends (x, y) to (x cos θ − y sin θ, x sin θ + y cos θ). A rotated graph is often no longer a function, so it cannot be written as y = f(x). A 180° rotation equals both reflections together.

Order of the changes

The tool applies the changes in this order: b and the y-axis reflection inside the function, then the shift h, then a and the x-axis reflection, then the shift k, and finally the rotation. When you read an equation such as y = −2f(3(x − 1)) + 4, work from the inside out: compress by 3, shift right 1, stretch by 2 and flip over the x-axis, then shift up 4. Doing the steps in a different order can give a different graph.

Guided practice

Try each problem on paper first, then press the line to see the solution. You can check any answer with the sliders above.

1. Start with y = x². Write the equation of the graph after it is shifted 3 units to the right and 2 units down.

Show solution
Right 3 means replace x with (x − 3). Down 2 means subtract 2 at the end.
y = (x − 3)² − 2. The vertex moves from (0, 0) to (3, −2). Check: the point (1, 1) on x² lands on (4, −1), and (4 − 3)² − 2 = −1.

2. Describe the graph of y = |x + 4| + 1 compared with y = |x|.

Show solution
x + 4 = x − (−4), so h = −4: the graph moves 4 units left. The + 1 outside moves it 1 unit up. The vertex goes from (0, 0) to (−4, 1).

3. The point (2, 5) is on the graph of y = f(x). Find the matching point on y = f(x − 3) + 1.

Show solution
The inside “− 3” moves points 3 to the right, so x becomes 2 + 3 = 5. The outside “+ 1” moves points up 1, so y becomes 5 + 1 = 6. The point is (5, 6). Check: f(5 − 3) + 1 = f(2) + 1 = 5 + 1 = 6.

4. Start with y = √x. Stretch it vertically by a factor of 3, reflect it over the x-axis, and shift it up 2. Write the new equation and find where the point (4, 2) goes.

Show solution
Stretch by 3: 3√x. Reflect over the x-axis: −3√x. Shift up 2: y = −3√x + 2. For the point: x stays 4, and y = −3(2) + 2 = −4. So (4, 2) goes to (4, −4).

5. The graph of y = f(x) contains (2, 5). Find the matching point on y = −f(x + 1).

Show solution
Inside: x + 1 = x − (−1), so points move 1 to the left: x becomes 2 − 1 = 1. Outside: the minus sign flips over the x-axis, so y becomes −5. The point is (1, −5).

6. Compress y = x² horizontally by a factor of ½. Write the equation and say where (2, 4) goes.

Show solution
Compressing horizontally by ½ means every x is divided by 2, so use b = 2 inside: y = (2x)² = 4x². The point (2, 4) goes to (2 / 2, 4) = (1, 4). Check: 4(1)² = 4. Notice that for a parabola this looks the same as a vertical stretch by 4.

7. Write the equation of a parabola with vertex (−2, 3) that opens downward and has the same width as y = x².

Show solution
Start with x². Moving the vertex to (−2, 3) gives (x + 2)² + 3 (left 2, up 3). Opening downward adds a reflection over the x-axis, so put a minus sign in front of the squared part: y = −(x + 2)² + 3. Check: at x = −2 the value is 3, and every other point is lower.

8. Describe every change from y = f(x) to y = 2f(−x + 4) − 1. (Hint: factor the inside first.)

Show solution
−x + 4 = −(x − 4). So the function is 2f(−(x − 4)) − 1. Inside: reflect over the y-axis, then shift right 4. Outside: stretch vertically by 2, then shift down 1. A point (x, y) goes to (4 − x, 2y − 1).
